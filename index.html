    Threat Intel Malware Analysis 2026-06-09
    An Invoice Lure That Installs a Rogue ManageEngine Endpoint Central Agent

    A multi-stage VBScript chain invoice lure disables UAC, then silently installs a genuine, Zoho-signed ManageEngine Endpoint Central agent pre-configured to enrol with an attacker-controlled server at 38.55.151[.]63:8383. The payload is the real, clean RMM installer. The malice lives entirely in the delivery chain, the enrolment config, and a pair of attacker-generated root CAs, turning a trusted enterprise tool into a fully-featured backdoor.

    Threat Intel Malware Analysis 2026-06-01
    UNC5342 Blockchain Dead-Drop Loader

    Pivoting from Socket's 31 May report on a Famous Chollima loader in a Packagist PHP package, I used the obfuscator's in-file decoder signature as a VirusTotal content selector to surface a second victim: a Spanish padel-club SaaS product with the same builder injected into one route module. The loader runs four nested decode layers and resolves its payload as a blockchain dead-drop — a TRON (Aptos fallback) transaction pointer feeding an XOR-encrypted body pulled from BNB Smart Chain RPC, then executed via eval() and a detached node -e child. Same wallets, accounts, and keys as the Socket sample; only the campaign marker and host file differ.
    Malware Analysis 2026-05-28
    A Five-Stage PowerShell HTTP RAT Hidden Behind an Employee Resume Lure

    A resume-themed .docm staged on 42web[.]io reconstructs an encrypted PowerShell loader through five layers of base64 and XOR, installs a scheduled task masquerading as a Microsoft Edge Update job, and ultimately runs a custom HTTPS RAT that beacons every ~30s with cmd/powershell/upload/download primitives. Includes six new Elastic detection rules closing the gaps the default ruleset missed.
